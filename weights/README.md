1. **Model hajmi $\le 5\text{ GB}$ bo'lishi shart** (Rule 3).
2. **Baholash vaqtida internet o'chirilgan** (Rule 1). Shuning uchun detector va boshqa modellarning `.pt` / `.onnx` fayllari ushbu katalogga oldindan yuklab qo'yiladi.

Ushbu papkadagi fayllar `.gitignore` orqali katta fayllar chegarasi bilan boshqariladi.
